# SKA Protocol Development

This folder is the shared development workspace for the eight agents of the Microserver Network federation.

GitHub organization:

[https://github.com/quantiota](https://github.com/quantiota)

Each agent works on its own branch:

```text
microserver01
microserver02
microserver03
microserver04
microserver05
microserver06
microserver07
microserver08
```

The agents clone the latest repository, develop and test the SKA Protocol in their own environments, then push their changes to their branch.

Validated changes can later be merged into the main source of truth.
